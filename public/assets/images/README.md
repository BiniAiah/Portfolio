# Images

Drop your own pictures in this folder and update the paths in `src/data/portfolio.ts`.

## Recommended files

| File | Used for | Suggested size |
| --- | --- | --- |
| `profile.png` | Hero profile photo | Square, 640x640 or larger |
| `project-bangkago.png` | BangkaGo project card | 16:10, 800x500 or larger |
| `project-senior.png` | Senior Citizen Assistance project card | 16:10, 800x500 or larger |
| `project-jkl.png` | JKL Vince Furniture project card | 16:10, 800x500 or larger |
| `favicon.svg` | Browser tab icon | 64x64 |
| `og-image.png` | Social share preview | 1200x630 |

The `.svg` files currently in this folder are placeholders. You can either:

1. Replace the placeholder `.svg` files with your own images and keep the same file names, or
2. Add new files (for example `profile.png`) and update the matching path in `src/data/portfolio.ts`.

If a project image is missing, the site gracefully falls back to the placeholder.
